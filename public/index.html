Quick guide

Control

Use Show Modes for fast switches. Game = Xbox + facecam. BRB and Ending mute the main mic automatically.

Viewer

Shows snapshots of the current Program output. Use it as a confidence monitor while your main display stays clear.

Sounds

Upload MP3/WAV/etc. or record a voice clip. Tap a pad to route it through the OBS soundboard source.

AI

The assistant sees current OBS state and can execute approved studio actions. Your API key stays on the Mac.

Green screen

Camera above background, Chroma Key on camera, even green-screen lighting, and a little space between you and the screen.

Audio

Use the Mini mic as the main stream mic. Set it Mono in Advanced Audio Properties if it only plays in one ear.

Remote access

Use obsremote.liv8.co through Cloudflare. Never expose raw OBS WebSocket port 4455 publicly.

Mobile

Add the site to your home screen. The bottom navigation and touch controls are designed for phone and tablet use.
