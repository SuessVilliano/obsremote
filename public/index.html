QUICK GUIDE

How to use OBS Remote

1. Control

Use Show Mode for fast scene changes. Game brings up Xbox + facecam. Xbox Full removes the facecam. BRB and Ending mute your main mic automatically.

2. Viewer screen

The Viewer tab requests screenshots of the current OBS Program scene. It is a low-bandwidth confidence monitor, so expect a short delay rather than full-motion video.

3. Custom sounds

Upload an audio file or record a voice clip. Press the large pad to fire it through an OBS Browser Source. The first play in a new scene may take a moment while the source is added.

4. AI assistant

Add an OpenAI API key to the Mac’s .env file to enable AI. The key stays on the Mac server and is never sent to your tablet. The assistant only receives the OBS context needed for the request.

5. Green screen

Keep your Logitech camera source above the background source. Apply a Chroma Key filter to the camera. Light the green screen evenly and keep some distance between you and the fabric.

6. Audio

Keep the Mini mic as your main stream mic and set it to Mono in OBS Advanced Audio Properties if it plays in one ear. Mute the webcam mic unless you intentionally need it.

7. Anywhere access

Your Cloudflare hostname can reach this command center from phone, tablet, or computer. Keep raw OBS WebSocket port 4455 private; only the command-center server should talk to it.

8. Safety

Start/Stop Stream still requires deliberate control. The AI server also refuses to trigger streaming unless your message explicitly asks to start or stop the stream.
